Formulatrix builds automated liquid-handling instruments for laboratories. I built the software that operates them.

These instruments run unattended, so the interface has to show the machine's real state and make the next action obvious. I shipped the control software for the aµtoPulse v4 and Reagent Exchanger, added live camera streaming from inside a running instrument, and built an MQTT pipeline that moved production data off the hardware into dashboards laboratory managers could use directly.
