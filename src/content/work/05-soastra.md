A multi-agent orchestration platform in Python. Frontier models handle planning and review; bounded implementation is routed to lower-cost workers on Hermes, OpenRouter and DeepSeek.

Roles, personas, skills and providers are registries. Work compiles to a dependency graph and executes in waves, each task isolated in its own git worktree behind deterministic completion checks and verified retries. The first full run delivered nine Swoop Autos features in parallel for roughly the cost of one.
